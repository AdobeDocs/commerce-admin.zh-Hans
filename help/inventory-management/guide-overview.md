# [!DNL Inventory Management] 概述

本指南适用于在Adobe Commerce和Magento Open Source中跨多个位置管理库存的管理员。 它提供[!DNL Inventory Management]模块的配置和管理过程，并假定您对核心[!DNL Commerce]功能有基本的了解。

使用&#x200B;**管理员**&#x200B;执行配置、报告和日常清单任务。 使用&#x200B;**命令行界面**&#x200B;进行安装、升级和后端配置。

本指南涵盖：

| 主题 | 描述 |
| ------- | ----------- |
| [简介](introduction.md) | 功能、术语以及[!DNL Inventory Management]如何适合您的商店。 |
| [发行说明](release-notes.md) | 模块版本历史记录和已知问题。 |
| [清单基础知识](sources-stocks.md) | [库存和来源](sources-stocks.md)、[来源选择和预订](selection-reservations.md)、[订单和预订状态](order-status.md)以及[产品类型](product-types.md)的概念。 |
| 快速入门 | [Commerce升级](migrate.md)、[安装和更新](install-update.md)、[商家采购类型](merchant-sourcing.md)和[库存重组](expand-restructure.md)。 |
| [配置](configuration.md) | 店面展示和发货的全局、产品和算法设置。 |
| [管理源](sources-manage.md) | 创建和维护履行地点。 |
| [管理库存](stocks-manage.md) | 将源映射到销售渠道。 |
| [管理数量](quantities-manage.md) | 按来源分配和更新产品数量。 |
| [管理订单和装运](shipments.md) | 完成订单并管理库存发运。 |
| [CLI引用](cli.md) | 命令行清单和配置任务。 |
